# SORA

熱気球のフライトを、誰でもすぐに。

ブラウザだけで動く熱気球のシミュレーターです。インストールは要りません。
地形は国土地理院の標高データから組み立てているので、実在の場所の上を飛べます。

- **ホーム・はじめての遊び方** → <https://rhitomigm-hash.github.io/SORA/>
- **すぐ遊ぶ** → <https://rhitomigm-hash.github.io/SORA/prototype/>
- **操作のしかた（はじめての方へ）** → <https://rhitomigm-hash.github.io/SORA/tutorial.html>

## 熱気球は上下しか操作できません

飛行機やドローンと違い、熱気球には推進装置がありません。できるのは
**上がる**か**下がる**かだけです。

空の風は高さによって向きも速さも変わるので、
**行きたい方向へ吹いている高さまで上下して、その風に乗る** — これが操縦です。
「高さを選ぶこと」が「方向を選ぶこと」になります。

## 操作

| 操作 | キーボード | タッチ |
|---|---|---|
| バーナー（上昇・長押し） | `Space` | 🔥 |
| リップライン（下降・長押し） | `R` | RIP |
| マーカー投下 | `M` | 📍 |
| 視点切替（ゴンドラ／外部） | `V` | 👁 |
| 時間加速 ×1/×2/×4/×8 | `1`〜`4` | ×1 |
| パイバル表（高度別の風） | `P` | P |

視点回転はドラッグ、ズームはホイール（タッチはピンチ）。

## モード

- **既定** … 開いてすぐ飛べます
- **本格モード** … エリア・風・離陸地点を自分で決めます。競技は JDG
  （目標にマーカーを落とし、目標中心からの距離を競う）。
  設定は「条件URLをコピー」で共有でき、同じ条件で勝負できます
- **飛行ログ(IGC)** … 手元の飛行ログを 3D で表示します。
  「見る」「飛ぶ（復習）」「なぞる（検証）」の3つ。
  **読み込んだファイルは外部に送信されません**（ブラウザ内だけで処理します）

### 地上クルー（開発途中）

「本格モード」→「開発途中版」の離陸前画面で **地上クルーあり** を選べます。
既定はオフです。白い車は気球を追尾し、青い車はターゲット付近へ先行・待機します。
PDGでは青い車は宣言した目標へ向かいます。
離陸後、**Cキー** または **地上クルー・無線** パネルを開くと、両車の現在地と地上風を報告します。
「現在地の風を聞く」で報告を更新できます。風向はFROM・磁方位、風速はノットです。

道路は離陸地点から順に取得します。読み込めない場所でも気球の飛行は続けられます。
青い車の100m以内への進入制限はゲーム内設定であり、実競技の規則・安全基準ではありません。
条件URLにも参加選択を引き継ぎます（`?dev=1&road=1`）。
IGCモードには地上クルーを追加しません。黄色い車の操作・回収ゲームはGameTargetに残します。

## ローカルで動かす

ルートの `index.html` が起動画面です。`guide.css` と `png/` の画像を同じリポジトリに含め、
ゲーム・本格モード・IGC・チュートリアルへ相対リンクで案内します。
ホームの解説と画像はGameTargetの `balloon-guide.html` をもとにしています。
ローカルでは <http://localhost:8002/> から開けます。

気球ゲームの実装・修正先は、このリポジトリの `prototype/` です。
EarthHealthは観測・分析を担当し、ホームページとIGC分析ツールからSORAへ直接リンクします。
EarthHealthには気球ゲームのコードや `prototype/` フォルダーを置きません。
風モデルはEarthHealthで分析・検証し、採用が決まったものをSORAへ反映します。
GameTargetのチェイスカー・マーカー回収ゲームは別に開発します。

`main.js` が `terrain.js` を `import` する ES モジュール構成のため、
HTML を直接ダブルクリックしても動きません（ブラウザが `file://` からの
import を拒否します）。簡易サーバー経由で開いてください。

```
python -m http.server 8002
```

→ <http://localhost:8002/prototype/>

`tutorial.html` は単独の HTML なので、こちらはダブルクリックで開けます。

## ご注意

SORA は競技のシミュレーターです。**実際の運航の判断には使えません。**
実際の気象や運航の判断は、気象庁の発表を確認してください。
